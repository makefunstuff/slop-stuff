Every link was checked with curl (HTTP status) at build time. 82 returned 200; 8 returned 403/402 — those are real sites that bot-block curl but load fine in a browser (All About Circuits, DigiKey, Raspberry Pi, SEC EDGAR, Stack Overflow, GNU Radio, Investopedia, crates.io).
